# SolarGuard

Monitoramento e previsão de geração fotovoltaica para várias plantas: coleta por conectores, alertas auditáveis, painel web e acesso para IA via MCP.

Projeto Integrador IV da UNIVESP. O plano está em [docs/PLANO.md](docs/PLANO.md).

```bash
make check
make build
./bin/solarguard migrate
```
